Warum die Mac-App

Alles, was die Web-Version kann — schärfer, schneller, nativer.

Die Browser-Version ist bereits ein vollständiges Werkzeug. Die Mac-App ergänzt das, was nur ein natives Binary bieten kann: echte Metal-Beschleunigung, Verknüpfung von GPX-Dateien mit dem System, haptisches Force-Touch-Feedback auf kompatiblen Trackpads und flüssiges Rendering selbst bei langen mehrtägigen Durchquerungen.

Metal-beschleunigtes 3D

Native WKWebView mit Metal — das 3D-Gelände bleibt flüssig, selbst bei steilem Neigungswinkel auf langen Routen.

Finder-Integration

Doppelklicken Sie eine beliebige .gpx-Datei im Finder, um sie in GPX Map 3D zu öffnen — kein Drag-and-Drop mehr nötig.

Force-Touch-Haptik

Macs mit Force-Touch-Trackpad erhalten ein subtiles haptisches Feedback, sobald ein Wegpunkt an der Route einrastet.

Signiert und notarisiert

Signiert mit unserer Apple Developer ID und von Apple notarisiert — öffnet sich mit einem Klick auf jedem Mac.

Funktioniert 100% offline

Einmal installiert, startet und läuft die App ohne Verbindung. Cachen Sie die Kacheln einer Tour vor — und Sie sind bereit.

100% kostenlos, für immer

Kein Abo, keine zeitlich begrenzte Testversion. Die gesamte App gehört Ihnen, mit allen freigeschalteten Funktionen.

Funktionen

Für Wanderer, die jedes Detail wollen.

Eine Route von Grund auf planen

Tippen Sie auf die Karte, um einen Wegpunkt zu setzen; BRouter (Profil hiking-mountain) routet automatisch zwischen den Wegpunkten auf echten Wegen und Pfaden. Ziehen Sie einen Wegpunkt, um die Form anzupassen. Tippen Sie auf eine Segmentlinie, um einen neuen Wegpunkt zwischen zwei bestehenden einzufügen.

  • Live-Höhenprofil + Munter-Zeit während der Routenführung
  • Ortssuche mit Autocomplete (Photon) — springen Sie zu "Berchtesgaden", "Zugspitze", "Hörnlihütte"
  • Schließen Sie die Route per Tap auf den ersten Wegpunkt zu einer Schleife
  • Direkter .gpx-Download — nutzbar mit Garmin, Strava, Komoot

Cinematische 3D-Wiedergabe

Beobachten Sie, wie Ihre GPX-Datei echtes 3D-Gelände durchquert — mit animierter Chase-Kamera. Passen Sie Neigung, Überhöhung, Verfolgungsmodus (Chase / Topdown / Seitenansicht) und Geschwindigkeit an. Der Kino-Modus blendet die UI aus, für eine immersive Ansicht im Stil von Fotos.app.

  • Echtes Relief aus dem DEM AWS Open Data
  • Drei Verfolgungsmodi — Chase, Topdown, Seitenansicht
  • Kino-Modus — drücken Sie F, um die gesamte UI auszublenden
  • Drücken Sie Play und lassen Sie es laufen — autonomer Flug

Beliebige GPX-Dateien bearbeiten

Legen Sie eine bestehende .gpx-Datei ab und wechseln Sie in den Bearbeitungsmodus. Die Route wird (Ramer-Douglas-Peucker) auf etwa 30 editierbare Wegpunkte heruntergerechnet; BRouter routet erneut zwischen ihnen. Ziehen, einfügen, löschen, einen Umweg erweitern oder einen veralteten Abschnitt entfernen. Speichern Sie als sauberes .gpx oder als .gxm-Bundle (mit Fotos und Annotationen).

  • Intelligentes Subsampling, das die Form bewahrt
  • Ziehen Sie einen Wegpunkt, um einen Abschnitt umzuformen
  • Klicken Sie zwischen zwei Wegpunkte, um einen neuen einzufügen
  • Annotieren Sie (Name, Beschreibung, Foto) — exportiert als <wpt>

  • Kein Login. Niemals.

App-Privatsphäre

Der Entwickler erfasst keine Daten.

Kein Tracking. Keine Konten. Kein Upload.

GPX Map 3D erfasst keinerlei personenbezogene Daten, verlangt kein Konto und überträgt weder Routen, Fotos noch Annotationen an irgendeinen Server. FAQ

Häufig gestellte Fragen.

Funktioniert die App auf meinem Mac?

Die Mac-App benötigt macOS 11 (Big Sur) oder höher und einen Apple-Silicon-Chip (M1, M2, M3, M4). Wenn Sie einen Intel-Mac haben, läuft auf www.gpxmap3d.com im Browser exakt derselbe Code — ganz ohne Installation.

Werde ich "GPX Map 3D ist beschädigt" sehen?

Nein. Die App ist mit unserer Apple Developer ID signiert und von Apple notarisiert. Sie öffnet sich mit einem Klick auf jedem Mac — kein Rechtsklick → Öffnen, kein Terminal-Befehl. Falls Sie eine Gatekeeper-Warnung sehen, wurde der DMG-Download beschädigt — laden Sie ihn erneut herunter und versuchen Sie es nochmals.

Ist sie wirklich kostenlos?

Ja, vollständig kostenlos. Keine Testversion, kein Premium-Abo, keine In-App-Käufe. Alle Funktionen stehen allen kostenlos zur Verfügung. Wir bezahlen die 99 $/Jahr für die Apple-Developer-Mitgliedschaft aus eigener Tasche, damit Sie es nicht tun müssen.

Wie installiere ich sie?

Klicken Sie oben auf der Seite auf die Schaltfläche "Herunterladen", öffnen Sie das heruntergeladene .dmg und ziehen Sie das GPX-Map-3D-Symbol in Ihren Programme-Ordner. Fertig — starten Sie sie über Spotlight oder das Launchpad.

Was ist der Unterschied zwischen der Mac-App und der Browser-Version?

Dieselben Funktionen, derselbe Code. Die Mac-App ergänzt: native Verknüpfung von Finder-Dateien (doppelklicken Sie eine beliebige .gpx-Datei zum Öffnen), haptisches Force-Touch-Feedback auf kompatiblen Trackpads, echte Metal-Beschleunigung und die Fähigkeit, offline zu starten (die Browser-Version benötigt einen Online-Besuch zum Cachen).

Erhalte ich automatische Updates?

Noch nicht — laden Sie aktuell die neueste DMG-Datei von dieser Seite herunter, wenn eine neue Version erscheint. Automatische Updates über den Tauri-Updater sind für v0.2 geplant.

Funktioniert sie offline?

Ja. Der Code der App läuft vollständig auf Ihrem Mac. Die 3D-Kartenkacheln benötigen standardmäßig eine Verbindung, aber Sie können die Kacheln für die BBox einer bestimmten Route im Offline-Bereich der Einstellungen vorab cachen — anschließend funktioniert die gesamte Erfahrung ohne Netzwerk.

Wo speichert die App meine Daten?

Die Einstellungen liegen in ~/Library/Preferences/com.flexweg.gpxmap3d.plist. Fotos und Bundles in ~/Library/Application Support/com.flexweg.gpxmap3d/. Der Kachel-Cache befindet sich im WKWebView-Cache. Nichts verlässt Ihr Gerät.

Wird es eine iPhone- und iPad-App geben?

Ja — die Codebasis ist bereits auf Tauri 2 Mobile portiert (die iOS-/iPadOS-Targets sind initialisiert). Die Einreichung im App Store läuft; rechnen Sie demnächst mit einem TestFlight-Einladungslink auf dieser Seite.

Wird es eine Windows- oder Linux-Version geben?

Kurzfristig wahrscheinlich nicht. Die Browser-Version auf www.gpxmap3d.com bietet denselben Funktionsumfang und läuft identisch auf Windows, Linux, ChromeOS und Android. Die native Mac-App existiert, weil Apple Silicon messbar bessere 3D-Performance liefert als der Web-Kontext auf denselben Chips.

Bereit, Ihre Tracks in 3D zu erleben?

Eine DMG-Datei, ein Drag-and-Drop, und Sie fliegen in 60 Sekunden über die Alpen.
