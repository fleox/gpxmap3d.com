Warum GPX Map 3D

Ein echter 3D-GPS-Viewer, der Ihre Zeit und Ihre Daten respektiert.

Die meisten GPS-Track-Viewer verstecken die besten Funktionen hinter einem Bezahl-Plan, erzwingen eine Registrierung oder laden Ihre Routen auf ihre Server. GPX Map 3D geht den umgekehrten Weg: alles wird lokal gerendert, alles ist kostenlos, nichts muss installiert werden.

100 % kostenlos, für immer

Jede Karte, jedes Overlay, jede Funktion. Keine Premium-Stufe, die das Wichtige verbirgt.

Ihre Routen bleiben privat

Die App läuft in Ihrem Browser. Tracks, Fotos und Markierungen werden nirgendwohin hochgeladen.

Funktionen

Alles, was Sie brauchen, um eine Tour neu zu erleben — und zu teilen.

Öffnen Sie eine GPX-Datei, sehen Sie sie auf 3D-Relief animiert, blättern Sie durchs Höhenprofil, prüfen Sie die Wochen-Wettervorhersage, fixieren Sie Ihre Fotos am richtigen Punkt und exportieren Sie alles als Video.

Animierte cinematische Kamera

Drei Folgemodi — Chase, Topdown, Seitenansicht. Ein Anti-Clip-Pass hält die Kamera auch in steilen Abstiegen über dem Gelände.

WebM-Video-Export

Nimmt die Wiedergabe als WebM-Datei in der Bildrate Ihres Bildschirms auf. Ideal für Instagram-Stories, YouTube oder Ihr persönliches Archiv.

Echtes Relief

Globales DEM in terrarium-Kodierung von AWS Open Data. Hillshade darüber gerendert, damit die Bergform in jeder Neigung lesbar bleibt.

Höhenprofil

Cursor synchron mit der Kamera, Sonnenauf-/-untergangs-Markierungen, optionales Overlay für Herzfrequenz / Trittfrequenz / Leistung aus den GPX-Erweiterungen.

Fotos an GPS-Koordinaten

Foto mit EXIF-GPS ziehen — landet am richtigen Ort. Ohne EXIF: lange auf die Karte drücken, um es manuell zu platzieren.

Benutzer-Markierungen

Lange auf die Karte drücken, um eine betitelte Annotation hinzuzufügen. Etappe 1, Biwak, Wasserquelle — Ihre Sache. Bleiben nach Reloads erhalten.

8-Tage-Wettervorhersage

Tägliche Open-Meteo-Vorhersage am Zentrum der Route. Höchst- / Tiefstwert / Niederschlag / Wind / Symbol pro Tag, ohne API-Key.

Trekking-POIs

Berghütten, Schutzhütten, Wasserquellen, Quellen und benannte Gipfel live aus OpenStreetMap (Overpass) im Routen-Bereich.

.gxm-Bundle-Export

Eine Datei, die Ihre GPX, Ihre Fotos, Ihre Markierungen und Ihre Anzeige-Einstellungen enthält — später re-importieren und alles wiederherstellen.

Alle Karten-Overlays mit einem Klick

Standardmäßig aktiv — im Anzeige-Panel deaktivieren, was Sie nicht brauchen.

GPX-Editor & Routenplaner

Planen Sie eine Wanderung von Grund auf — oder bearbeiten Sie eine bestehende GPX.

Tippen Sie auf die Karte, um Wegpunkte zu setzen. GPX Map 3D ruft BRouter auf und folgt automatisch Wanderwegen. Höhenprofil, Munter-Zeit und POIs werden bei jeder Bewegung aktualisiert. Im Browser, ohne Konto und ohne API-Schlüssel.

Tippen zum Setzen

Tippen Sie auf die Karte, um einen Wegpunkt hinzuzufügen. Der Pfad wird automatisch über BRouter (Wandermodus) berechnet und folgt echten Wegen und Pfaden.

Ziehen zum Verfeinern

Ziehen Sie einen Wegpunkt, um einen Abschnitt zu verschieben. Klicken Sie zwischen zwei Wegpunkten, um einen neuen einzufügen. Die Route wird live neu berechnet.

Orte suchen

Integrierte Suchleiste mit Autovervollständigung (Photon-Geocoder). Schreiben Sie „Annecy", „Mont Blanc" oder „Refuge du Goûter" und springen Sie sofort dorthin, um Ihren Wegpunkt zu setzen.

Live-Höhenprofil + Munter

Höhenprofil, kumulierter Auf-/Abstieg und Munter-Schätzzeit aktualisieren sich bei jeder Änderung. Sehen Sie den Schwierigkeitsgrad Ihrer Route, während Sie sie zeichnen.

POIs beim Planen

Gipfel, Hütten, Wasserquellen und Schutzhütten direkt in der Editor-Symbolleiste umschalten. Klickbare Symbole zur Validierung der Route an Schlüsselstellen.

Bestehende GPX bearbeiten

Importieren Sie eine GPX und arbeiten Sie sie nach. Verlängern Sie sie um einen Abstecher, verschieben Sie einen Wegpunkt, fügen Sie eine Schleife hinzu oder löschen Sie einen unerwünschten Abschnitt. Exportieren Sie das Ergebnis als saubere GPX.

Schleife schließen + annotieren

Klicken Sie auf den ersten Wegpunkt, um eine Schleife zu schließen. Öffnen Sie ein Modal pro Wegpunkt, um einen Namen, eine Notiz oder ein Foto hinzuzufügen — alles in der finalen GPX gespeichert.

100% im Browser

Keine Anmeldung, kein API-Schlüssel, kein Upload. Ihre Routen verlassen Ihr Gerät niemals. Doppelter Export: .gpx (Standard) oder .gxm (Bundle mit Fotos und Markierungen).

Häufig gestellte Fragen

Gute Fragen, ehrliche Antworten.

Kann ich eine GPX-Route von Grund auf planen?

Ja. Öffnen Sie den Planer, tippen Sie auf die Karte, um Wegpunkte zu setzen, und GPX Map 3D ruft BRouter (Wandermodus) auf, um die Strecke automatisch zu erzeugen — sie folgt echten Wegen und Pfaden. Höhenprofil, kumulierter Auf-/Abstieg und Munter-Zeit werden in Echtzeit aktualisiert. Exportieren Sie die fertige Route als .gpx, wenn Sie fertig sind.

Kann ich eine bestehende GPX-Datei bearbeiten?

Ja. Importieren Sie eine GPX, öffnen Sie den Editor und passen Sie sie an: einen Wegpunkt verschieben, einen neuen zwischen zwei Punkte einfügen, eine Schleife hinzufügen, einen Abstecher verlängern oder einen unerwünschten Abschnitt entfernen. Klicken Sie auf einen Wegpunkt, um einen Namen, eine Notiz oder ein Foto hinzuzufügen. Exportieren Sie das Ergebnis als saubere .gpx oder als .gxm-Bundle, wenn Sie Fotos und Markierungen aufbewahren möchten.

Ist GPX Map 3D wirklich kostenlos?

Ja — komplett kostenlos, ohne Anmeldung, ohne Testphase, ohne Premium-Stufe. Es gibt nirgendwo Werbung. Alle Funktionen (3D-Gelände, cinematische Kamera, Video-Export, Wetter, POIs, Fotos, Offline-Modus) stehen jedem ohne Kosten zur Verfügung.

Werden meine GPX-Dateien auf einen Server hochgeladen?

Nein. Die gesamte App läuft in Ihrem Browser. Ihre GPX-Dateien, Fotos und Anmerkungen verlassen Ihr Gerät niemals — kein Upload, keine Cloud, keine Telemetrie über Ihre Routendaten.

Funktioniert GPX Map 3D auf Smartphone oder Tablet?

Ja. Die Oberfläche passt sich an kleine Bildschirme an und unterstützt Touch-Gesten (Pinch-Zoom, Schwenken, langes Drücken zum Hinzufügen eines Punkts). Sie können sie auch als PWA aus dem Browser des Smartphones installieren, für eine App-ähnliche Vollbild-Erfahrung.

Welche Dateiformate werden unterstützt?

Import: .gpx, .kml und .gxm (das native Bundle-Format, das eine Route mit ihren Fotos und Markierungen enthält). Export: WebM-Video der Wiedergabe und .gxm-Bundles für Backup und Weitergabe.

Funktioniert GPX Map 3D offline?

Ja. Nach dem ersten Besuch wird die App im Cache abgelegt und funktioniert ohne Internetverbindung. Sie können auch die Kartenkacheln für den Bereich Ihrer Route vorladen, damit die 3D-Karte ebenfalls offline lädt.

Wie unterscheidet es sich von Strava oder Komoot?

GPX Map 3D ist ein kostenloser Viewer ohne Konto und ein Video-Exporter — keine Social-Plattform und kein Routenplaner. Es konzentriert sich auf die cinematische 3D-Wiedergabe einer bestehenden GPX-Datei: echtes Gelände, cinematische Kamera, Video-Export. Es gibt keinen Community-Feed, keine Routing-Engine, keine Bestenlisten.

Kann ich ein Video für Instagram oder YouTube exportieren?

Ja. Die Aufnahme-Schaltfläche erfasst die laufende Wiedergabe als WebM-Video in der Canvas-Auflösung und der gewählten Bildrate. Wenn Ihre Zielplattform kein WebM akzeptiert, konvertieren Sie mit einem Tool wie HandBrake nach MP4.

Kann ich es als App installieren?

Auf jedem Gerät ist die Seite als Progressive Web App installierbar. Unter Android Chrome erscheint automatisch eine Installations-Aufforderung. Unter iOS Safari verwenden Sie Teilen → Zum Home-Bildschirm hinzufügen. Es gibt auch eine native macOS-App — gebaut mit Tauri.
