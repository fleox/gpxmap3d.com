Funcionalidades

Pensada para caminhantes que querem cada detalhe.

Planeie uma rota de raiz

Toque no mapa para colocar um waypoint; o BRouter (perfil hiking-mountain) faz automaticamente o routing entre waypoints pelos trilhos e caminhos reais. Arraste um waypoint para remodelar. Toque numa linha de segmento para inserir um novo waypoint entre dois existentes.

  • Perfil de elevação + tempo Munter ao vivo durante o traçado
  • Pesquisa de locais com autocompletar (Photon) — salte para "Lisboa", "Serra da Estrela", "Refúgio do Goûter"
  • Feche um loop tocando no primeiro waypoint
  • Transferência direta .gpx — utilizável no Garmin, Strava, Komoot

Leitura 3D cinematográfica

Veja o seu GPX a atravessar um relevo 3D real com uma câmara chase animada. Ajuste o pitch, a exagerão, o modo de seguimento (chase / vista de cima / lateral) e a velocidade. O modo cinema esconde a UI para uma vista imersiva ao estilo da app Fotos.

  • Relevo real a partir do DEM AWS Open Data
  • Três modos de seguimento — chase, vista de cima, lateral
  • Modo cinema — prima F para esconder toda a UI
  • Prima play e deixe correr — voo autónomo

Edite qualquer GPX

Largue um .gpx existente e passe para o modo de edição. A rota é subamostrada (Ramer-Douglas-Peucker) em ~30 waypoints editáveis; o BRouter faz o re-routing entre eles. Arraste, insira, elimine, prolongue um desvio ou remova uma secção desatualizada. Guarde como .gpx limpo ou como bundle .gxm (com fotos e anotações).

  • Subamostragem inteligente que preserva a forma
  • Arraste um waypoint para remodelar uma secção
  • Clique entre dois waypoints para inserir um novo
  • Anote (nome, descrição, foto) — exportado como <wpt>

  • Sem login. Nunca.
  • Sem analytics, sem tracking
  • Toda a persistência é local (Application Support)

FAQ

Perguntas frequentes.

A app vai funcionar no meu Mac?

A app Mac requer macOS 11 (Big Sur) ou superior e um chip Apple Silicon (M1, M2, M3, M4). Se tem um Mac Intel, a versão para navegador em www.gpxmap3d.com corre exatamente o mesmo código sem precisar de instalação.

Vou ver "GPX Map 3D está danificada"?

Não. A app está assinada com o nosso Apple Developer ID e notarizada pela Apple. Abre com um único clique em qualquer Mac, sem clique-direito → Abrir, sem comando no Terminal. Se vir um aviso do Gatekeeper, é porque a transferência do DMG ficou corrompida — transfira novamente e tente outra vez.

É mesmo gratuita?

Sim, totalmente gratuita. Sem versão de teste, sem nível premium, sem compras integradas. Todas as funcionalidades estão disponíveis para toda a gente, sem custos. Pagamos os 99 $/ano da Apple Developer do nosso bolso para que não tenha de o fazer.

Como a instalo?

Clique no botão Transferir no topo da página, abra o .dmg transferido e arraste o ícone do GPX Map 3D para a pasta Aplicações. Está feito — abra-a a partir do Spotlight ou do Launchpad.

Qual é a diferença entre a app Mac e a versão para navegador?

Mesmas funcionalidades, mesmo código. A app Mac acrescenta: associação nativa dos ficheiros no Finder (duplo clique em qualquer .gpx para o abrir), feedback háptico Force Touch nos trackpads compatíveis, verdadeira aceleração Metal e a capacidade de abrir offline (a versão para navegador precisa de uma visita online inicial para se colocar em cache).

Vou receber atualizações automáticas?

Ainda não — por agora, transfira o DMG mais recente desta página sempre que sair uma nova versão. A atualização automática através do updater do Tauri está prevista para a v0.2.

Funciona offline?

Sim. O código da app corre inteiramente no seu Mac. Os tiles do mapa 3D requerem ligação à Internet por predefinição, mas pode fazer pré-cache dos tiles para a bbox de uma rota específica na secção Offline das Definições — depois disso toda a experiência funciona sem rede.

Onde é que a app guarda os meus dados?

As preferências estão em ~/Library/Preferences/com.flexweg.gpxmap3d.plist. As fotos e os bundles ficam em ~/Library/Application Support/com.flexweg.gpxmap3d/. O cache de tiles está no cache do WKWebView. Nada sai da sua máquina.

Vai haver uma app para iPhone e iPad?

Sim — a base de código já está portada para o Tauri 2 mobile (os alvos iOS / iPadOS estão inicializados). A submissão à App Store está em curso; aguarde um link de convite TestFlight nesta página em breve.

Vai haver versão Windows ou Linux?

Provavelmente não a curto prazo. A versão para navegador em www.gpxmap3d.com oferece as mesmas funcionalidades e funciona de forma idêntica em Windows, Linux, ChromeOS, Android. A app Mac nativa existe porque o Apple Silicon entrega um desempenho 3D mensuravelmente superior ao do contexto web nos mesmos chips.
