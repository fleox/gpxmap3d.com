Pourquoi l'app Mac

Tout ce que fait la version web — en plus net, plus rapide, plus natif.

La version navigateur est déjà un outil complet. L'app Mac ajoute ce que seul un binaire natif peut offrir : vraie accélération Metal, association des fichiers GPX au système, retour haptique Force Touch sur les trackpads compatibles, et un rendu fluide même sur les longues traversées multi-jours.

3D accélérée Metal

WKWebView natif avec Metal — le relief 3D reste fluide même à fort pitch sur les longues routes.

Intégration Finder

Double-cliquez n'importe quel .gpx dans le Finder pour l'ouvrir dans GPX Map 3D — plus besoin de glisser-déposer.

Haptique Force Touch

Les Mac avec trackpad Force Touch reçoivent un retour tactile subtil quand un waypoint se cale sur le tracé.

Signée et notarisée

Signée avec notre Apple Developer ID et notarisée par Apple — s'ouvre en un clic sur n'importe quel Mac.

Fonctionne 100% hors-ligne

Une fois installée, l'app se lance et tourne sans connexion. Pré-cachez les tuiles d'un trek et vous êtes paré.

100% gratuite, à vie

Pas d'abonnement, pas d'essai limité dans le temps. L'app entière est à vous, avec toutes les fonctionnalités débloquées.

Fonctionnalités

Pensée pour les randonneurs qui veulent chaque détail.

Planifiez un tracé de zéro

Tapez sur la carte pour poser un waypoint ; BRouter (profil hiking-mountain) route automatiquement entre les waypoints sur les vrais sentiers et chemins. Glissez un waypoint pour reformer. Tapez sur une ligne de segment pour insérer un nouveau waypoint entre deux existants.

  • Profil altimétrique + temps Munter en direct pendant le tracé
  • Recherche de lieux avec autocomplétion (Photon) — sautez à "Annecy", "Mont Blanc", "Refuge du Goûter"
  • Bouclez en tapant sur le premier waypoint
  • Téléchargement direct .gpx — utilisable sur Garmin, Strava, Komoot

Lecture 3D cinématique

Regardez votre GPX traverser un vrai relief 3D avec une caméra chase animée. Ajustez le pitch, l'exagération, le mode de suivi (chase / vue du dessus / latéral) et la vitesse. Le mode cinéma masque l'UI pour une vue immersive style Photos.app.

  • Relief réel depuis le DEM AWS Open Data
  • Trois modes de suivi — chase, dessus, latéral
  • Mode cinéma — pressez F pour masquer toute l'UI
  • Pressez play et laissez tourner — vol autonome

Modifiez n'importe quel GPX

Déposez un .gpx existant et passez en mode édition. Le tracé est sous-échantillonné (Ramer-Douglas-Peucker) en ~30 waypoints éditables ; BRouter re-route entre eux. Glissez, insérez, supprimez, étendez un détour ou enlevez une section obsolète. Sauvegardez en .gpx propre ou en bundle .gxm (avec photos et annotations).

  • Sous-échantillonnage intelligent qui préserve la forme
  • Glissez un waypoint pour reformer une section
  • Cliquez entre deux waypoints pour en insérer un
  • Annotez (nom, description, photo) — exporté en <wpt>

Tout reste sur votre Mac

L'app tourne entièrement sur votre machine. Vos fichiers GPX, vos photos et vos plans de tracé ne quittent jamais votre appareil — pas d'envoi, pas de sync cloud, pas de compte, pas de télémétrie. Même la météo optionnelle est récupérée anonymement sans aucune info identifiante.

  • Pas de login. Jamais.
  • Pas d'analytics, pas de tracking
  • Toute la persistance est locale (Application Support)
  • Mentalité open source, dépendances transparentes

Confidentialité

Le développeur ne collecte aucune donnée.

Pas de tracking. Pas de comptes. Pas d'envoi.

GPX Map 3D ne collecte aucune donnée personnelle, ne demande pas de compte, et ne transmet aucun tracé, photo ou annotation à aucun serveur. Les seuls appels réseau sont des fetches directs de données cartographiques publiques (OpenFreeMap, tuiles relief AWS, POI Overpass, météo Open-Meteo, routage BRouter) — aucun d'entre eux ne vous identifie.

  • Pas d'analytics
  • Pas de télémétrie
  • Pas de cookies
  • Pas de compte
  • Pas de pub
  • Pas de SDK tiers
  • Données GPX locales
  • Photos locales (IndexedDB)
FAQ

Questions fréquentes.

L'app marchera-t-elle sur mon Mac ?

L'app Mac requiert macOS 11 (Big Sur) ou supérieur et une puce Apple Silicon (M1, M2, M3, M4). Si vous avez un Mac Intel, la version navigateur sur www.gpxmap3d.com exécute exactement le même code sans installation.

Verrai-je "GPX Map 3D est endommagée" ?

Non. L'app est signée avec notre Apple Developer ID et notarisée par Apple. Elle s'ouvre en un clic sur n'importe quel Mac, sans clic-droit → Ouvrir, sans commande Terminal. Si vous voyez un avertissement Gatekeeper, c'est que le téléchargement du DMG a été corrompu — re-téléchargez et réessayez.

Est-ce vraiment gratuit ?

Oui, totalement gratuit. Pas d'essai, pas d'abonnement premium, pas d'achat intégré. Toutes les fonctionnalités sont disponibles pour tout le monde sans frais. On paie les 99 $/an d'Apple Developer de notre poche pour que vous n'ayez pas à le faire.

Comment l'installer ?

Cliquez sur le bouton Télécharger en haut de la page, ouvrez le .dmg téléchargé, et glissez l'icône GPX Map 3D dans votre dossier Applications. C'est fait — lancez-la depuis Spotlight ou Launchpad.

Quelle différence entre l'app Mac et la version navigateur ?

Mêmes fonctionnalités, même code. L'app Mac ajoute : association native des fichiers Finder (double-cliquez n'importe quel .gpx pour l'ouvrir), retour haptique Force Touch sur trackpads compatibles, vraie accélération Metal, et la capacité de se lancer hors-ligne (la version navigateur a besoin d'une visite en ligne pour se mettre en cache).

Aurai-je des mises à jour automatiques ?

Pas encore — pour le moment, téléchargez le dernier DMG depuis cette page quand une nouvelle version sort. La mise à jour auto via l'updater Tauri est prévue pour la v0.2.

Fonctionne-t-elle hors-ligne ?

Oui. Le code de l'app tourne entièrement sur votre Mac. Les tuiles cartographiques 3D nécessitent une connexion par défaut, mais vous pouvez pré-cacher les tuiles pour la bbox d'un tracé spécifique depuis la section Hors-ligne des Réglages — après quoi toute l'expérience marche sans réseau.

Où l'app stocke-t-elle mes données ?

Les préférences sont dans ~/Library/Preferences/com.flexweg.gpxmap3d.plist. Les photos et les bundles sont dans ~/Library/Application Support/com.flexweg.gpxmap3d/. Le cache des tuiles est dans le cache WKWebView. Rien ne quitte votre machine.

Y aura-t-il une app iPhone et iPad ?

Oui — la code base est déjà portée sur Tauri 2 mobile (les cibles iOS / iPadOS sont initialisées). La soumission App Store est en cours ; attendez-vous à un lien d'invitation TestFlight sur cette page bientôt.

Y aura-t-il une version Windows ou Linux ?

Probablement pas à court terme. La version navigateur sur www.gpxmap3d.com offre les mêmes fonctionnalités et marche identiquement sur Windows, Linux, ChromeOS, Android. L'app Mac native existe parce qu'Apple Silicon délivre des perfs 3D mesurablement meilleures que le contexte web sur les mêmes puces.
